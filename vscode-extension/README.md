# EZHTML for VS Code

Syntax highlighting, snippets and formatting for the EZHTML markup language.

## Features

- 🎨 **Syntax highlighting** for `.ezhtml` files
- ✨ **Snippets** for sections, cards, rows, tables, lists, forms and more
- ⌨️ **Auto-indentation** based on the indentation-driven grammar
- 🧹 **Whitespace formatter** (`> EZHTML: Format File`)
- 🌐 **Quick link** to the online docs (`> EZHTML: Open Documentation`)

## Installation

```bash
code --install-extension ezhtml
```

…or search for **EZHTML** in the Extensions panel.

## Snippet overview

| Trigger          | What it does                              |
| ---------------- | ----------------------------------------- |
| `section`        | Section with title + body                 |
| `row-cards`      | Two-column row with cards                 |
| `button`         | Primary button                            |
| `image`          | Image with alt text                       |
| `table`          | Two-column, two-row table                 |
| `list`           | Two-item bullet list                      |
| `form`           | Contact form (input, email, textarea, btn)|

## Configuration

None. The extension picks up `.ezhtml` files automatically.
