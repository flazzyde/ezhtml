# EZHTML v1.0.0 Release Notes

## Summary
First stable release of the EZHTML markup language and toolchain.

## Components
- `ezhtml` compiler CLI v1.0.0
- Electron-based editor v1.0.0
- VS Code extension v1.0.0
- 8 project templates
- Static website + browser playground

## Supported platforms
- Linux x86_64 (glibc, musl)
- Linux aarch64 (musl)
- macOS x86_64
- macOS aarch64
- Windows x86_64

## Assets
See `assets/EXPECTED_ASSETS.txt` for the complete list of binaries and bundles.

## Verification
Run `bash verify-release.sh` after dropping all assets into `assets/`.

## Checksums
SHA-256 checksums will be generated in `assets/SHA256SUMS.txt` after all binaries are present.
