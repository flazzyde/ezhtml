## EZHTML v1.0.0 — "Markdown for HTML"

The first stable release of the EZHTML markup language and toolchain.

- **Compiler:** a single statically-linked binary for Linux (glibc/musl x86_64
  and aarch64), macOS (Apple Silicon & Intel) and Windows.
- **Editor:** Electron desktop app with live preview and Monaco-backed code
  editing.
- **VS Code extension:** syntax highlighting, snippets, formatter.
- **Website:** landing page, docs hub, browser playground and roadmap.
- **Templates:** eight folder-based starters (blank, minimal, landing,
  portfolio, blog, dashboard, docs, company) -- each ships with assets
  for theming and per-page JavaScript.

See [`RELEASE_NOTES.md`](RELEASE_NOTES.md) for the full changelog and
[`assets/install.sh`](assets/install.sh) for the one-liner installer on
Linux/macOS. Discord: <https://discord.gg/TQs6McKJJs>.
