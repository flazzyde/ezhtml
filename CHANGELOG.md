# Changelog

All notable changes to **EZHTML** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial scaffolding of the EZHTML monorepo.
- Rust workspace for the compiler (`compiler/`).
- Electron + React + TypeScript editor (`editor/`).
- VS Code extension (`vscode-extension/`).
- Static website with playground (`website/`).
- 30+ `.ezhtml` example projects (`examples/`).
- Eight starter templates (`templates/`).
- Reference documentation under `docs/`.

## [0.1.0] – 2025-XX-XX

### Added
- First public release of the EZHTML compiler, the desktop editor,
  the VS Code extension and the marketing website.
- Support for all elements documented in `docs/Syntax.md`.
- CLI commands: `build`, `run`, `preview`, `init`, `doctor`, `format`,
  `lint`, `version`.
