Install the EZHTML Compiler

One static binary. Works on Linux, macOS and Windows.

macOS / Linux (one-liner)

curl -L https://ezhtml.org/install.sh | bash

Homebrew

brew install ezhtml

Windows (Scoop)

scoop install ezhtml

Cargo

cargo install ezhtml-cli

From source

git clone https://github.com/ezhtml/ezhtml.git
cd ezhtml/compiler
cargo build --release
./target/release/ezhtml --version
