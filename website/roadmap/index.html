Living roadmap

Where we are,
and where we're going.

EZHTML ships in quarterly slices. This page mirrors the canonical roadmap at docs/Roadmap.md — updated before every release, with the current quarter's milestones at the top.

  • ✅ Shipped in a tagged release
  • 🚧 In progress · code in flight
  • 🔜 Scheduled for current quarter
  • 💭 Considering · open discussion
✅

Shipped

Foundations of the language, the compiler, the editor and the public site.

  • Rust compiler MVP — tokenizer, parser, validator, emitter
  • All 28 documented elements + `` scaffold (OpenGraph, Twitter Cards)
  • Desktop editor with live preview & Monaco IntelliSense
  • VS Code extension (TextMate grammar, snippets, icons)
  • Browser playground, docs site, this roadmap, download page
  • 32 example projects · 8 starter templates (folder-based, with assets)
🚧

In progress

Work that has a branch or an open RFC.

  • WASM build of the compiler (playground + edge functions)
  • Snapshot test harness stabilised around insta
  • Faster editor preview — notify-based file watcher
  • Multiple-author project.ez support
🔜

Next · Q2 2026

Three streams run in parallel. Pick the one most relevant to you.

  • Compiler: lint as its own command with stylelint-style severity knobs
  • Editor: inline diagnostics gutter, per-template starter picker
  • Ecosystem: .ezplugin format v0, theme registry MVP, static site generator
💭

Considering

Open ideas. No commitment yet — speak up on Discord if one matters to you.

  • Language Server Protocol
  • Macro language for repeating sections
  • Component imports (à la JSX)
  • Visual diff between two .ezhtml files
  • Cloud build service (free + paid tiers)
  • Cursor / Windsurf support via LSP

Milestones · next 90 days

Each milestone has an acceptance criterion so we know when it's done — not "vibes".

  1. 🔜

    M1 · v0.3.0-rc.1

    target · end of Apr 2026
    • WASM build passes the compiler test suite (cargo test --target wasm32-unknown-unknown).
    • ezhtml.wasm npm package published.
    • Browser playground loads the WASM with no server round-trip.
    • Two templates re-recorded as snapshot tests.
  2. 🔜

    M2 · ezhtml lint as its own command

    target · May 2026
    • Accepts the same args as doctor and format.
    • Exit codes — 0 clean, 1 warnings, 2 errors.
    • New rules: line length, hard-tab usage, duplicate description.
  3. 💭

    M3 · Plugin format v0

    target · Q3 2026
    • Spec for .ezplugin written and merged.
    • One example plugin (x-easypie) shipped.
    • Errors point users to the SPEC when a plugin fails to load.
  4. 💭

    M4 · Theme registry MVP

    target · Q3 2026
    • theme "name" directive documented.
    • Three reference themes committed (midnight, ocean, paper).
    • CI smoke-tests each theme against the landing template.
  5. 💭

    M5 · Static site generator

    target · Q4 2026
    • ezhtml site src/ -o public/ walks a directory tree.
    • Generates index.html, per-folder index, RSS feed.
    • One site in examples/ proves the feature end-to-end.
  6. 💭

    M6 · LSP prototype

    target · Q4 2026
    • ezhtml-lsp binary speaks the LSP protocol.
    • Hover, go-to-definition and completion work in VS Code.
    • Released as a separate vscode-extension-lsp package.
