Features

Read the docs

🚀 Anfängerfreundlich

Einprägsame Schlüsselwörter statt kryptischem Markup. Du lernst EZHTML in 10 Minuten.

🪶 Kein Boilerplate

DOCTYPE, <head>, Meta-Tags, OpenGraph – alles wird automatisch erzeugt.

🧱 Einrückung = Hierarchie

Keine schließenden Tags. Keine vergessenen </div>. Strukturiert wie Python.

🛡️ Validator

Fehlende Alt-Texte, doppelte IDs, SEO-Issues – alles direkt im Editor.

⚡ Schnell

Eine einzige statische Rust-Binary. Kein Cold-Start, keine GC-Pausen.

🧩 Erweiterbar

Eigene Elemente, Themes, Plugins. MIT-lizenziert.

Install

# Cargo
cargo install ezhtml-cli

# Homebrew
brew install ezhtml

# Linux
curl -L https://ezhtml.org/install.sh | bash
