Features

Fast

Safe

Read the docs

🚀 Beginner-friendly

Memorable keywords instead of cryptic markup. You learn EZHTML in 10 minutes.

🪶 No boilerplate

DOCTYPE, <head>, meta tags, OpenGraph — everything is generated automatically.

🧱 Indentation = hierarchy

No closing tags. No forgotten </div>. Structured like Python.

🛡️ Validator

Missing alt text, duplicate IDs, SEO issues — all surfaced directly in the editor.

⚡ Fast

One single static Rust binary. No cold start, no GC pauses.

🧩 Extensible

Custom elements, themes, plugins. MIT-licensed.

Install

# Cargo
cargo install ezhtml-cli

# Homebrew
brew install ezhtml

# Linux
curl -L https://ezhtml.flazzy.de/install.sh | bash
